Start practicing

  1. Tap Open to choose a local audio file, or Tools → Demo.
  2. Adjust tempo and pitch; release a slider to apply. Reset both restores the original tempo and pitch.
  3. Set A and B at the playback position. Use Practice → Edit A–B times for millisecond wheels.
  4. Sound contains Equalizer and Separate A–B. Use Voice / Instrumental to compare completed results.
  5. Tools → Export WAV saves the whole file or selected range.

Common questions

Separation is limited to 0.5–20 seconds and uses the original audio, without tempo, pitch or EQ effects. It can introduce artifacts; it cannot guarantee studio-quality isolated vocals.

Keep TempoLab open during separation. Cancel, leaving the app or low memory can prevent completion; previous completed results remain. Cancellation waits for the current native calculation to finish safely.

If import fails, copy the file locally and try a mono/stereo MP3 or WAV. Free storage is required for decoded audio and exported files. Pause playback before switching to another app that plays sound.

Private files and settings are removed by clearing app storage or uninstalling. Exported WAV files remain where you saved them. There are no user accounts to delete.
