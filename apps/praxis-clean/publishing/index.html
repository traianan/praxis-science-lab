Short description

Review storage, select photos in a grid and manage recoverable local trash.

Full description

A storage and file-review toolkit for Android, currently in testing.

Explore accessible storage, review leftover and unnecessary files, find duplicates, and select multiple photos in a three-, four- or five-column gallery. After moving a selection to local trash, continue with the remaining photos. Review operations and restore eligible files from History.

The toolkit also includes app management, optional cache assistance, image compression to a new copy, exclusions, scheduled scans and contextual battery reports. Android permissions determine what each tool can access. Scheduled scans do not delete files automatically.

Choose English, Romanian or Spanish from the visible language control. A compact, adaptive home screen and a global navigation menu provide access to the tools.

The evaluation build offers an optional Google test-ad check in Settings. The planned model combines advertising with a one-time purchase; commercial purchasing is not configured. There is no Google Play release or public APK download on this page.

Data safety worksheet

Preparation only. Review the final signed artifact, active advertising and purchase configuration, and provider behavior before completing Google Play declarations.

File review processes names, paths, sizes, modification times, content fingerprints, thumbnails and compression locally. The local journal stores operation states, file references and fingerprints for verification and restoration. Photo selections, language and other preferences stay on the device. Installed-app inventory supports file ownership and app management; optional usage access supports exclusions. No developer-operated account is required.

Storage access is requested according to the selected tool. Usage access, Shizuku, root and Accessibility are optional and can be refused or revoked. The app does not root the device. After individual confirmation, cache assistance inspects a recognized Android Settings screen for up to 45 seconds and performs at most one supported Clear cache action; it does not retain screen text or use it for advertising.

The evaluation build includes Google Mobile Ads and UMP with test identifiers. An optional test in Settings checks applicable consent before requesting ads. Google services may process IP addresses, approximate location, identifiers, interactions and diagnostics. Test advertising can still transmit data. Google privacy: https://policies.google.com/privacy . The app does not intentionally supply file contents, paths, installed-app inventory, usage records or the operation journal to advertising services.

There is no Billing SDK or separate analytics SDK in this version. User-initiated exports use the chosen document provider, which may synchronize files under its own terms. Default journal exports omit paths and hashes; an optional detailed export includes them. Android automatic app backup is disabled.
