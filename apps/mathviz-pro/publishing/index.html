Full description

MathViz Pro is an offline Android graphing calculator. Plot explicit functions, implicit equations, inequalities, polar curves and point tables. Pan, zoom and inspect approximate coordinates. Equal axis scaling keeps circles round when the graph area changes.

Explore parameter sliders and animations, import two-column CSV/TSV data and save graphs locally with thumbnails. Export PNG, PDF, LaTeX, vector SVG and animated GIF files to a location you choose.

Math tools provides step-by-step derivatives for supported functions and linear or quadratic least-squares fits for tables. Classroom mode enlarges the graph, while Practice includes 10 local questions with explanations. English, Romanian and Spanish are included.

All graphing tools are free. The development editions show test advertisements and include a planned one-time Remove Ads purchase. Commercial purchase products and production signing are not configured. No subscription, account or cloud synchronization is required or included. The app is in testing; there is no public store release or APK download on this page.

Data safety worksheet

The app has no developer-operated graph backend. Advertising and billing SDK behavior must still be declared for the exact Google/Huawei release. Test ads do not imply that no provider connection or device information is processed. Store declarations are pending.

Graphs, expressions, table values, parameters, thumbnails, language preferences and the viewed region are stored on the device. Mathematical calculations run locally. There is no MathViz account, remote graph database or cloud synchronization. Exported files are written only to the destination selected in the Android document picker.

The Google edition integrates Google Mobile Ads/UMP and Play Billing. The Huawei edition integrates Huawei Ads/Consent and IAP separately. Advertising services can process device identifiers, network information, interactions and diagnostics under their own policies, including during test advertising. Google or Huawei handles store payments; the developer does not receive payment-card details. Verified purchase evidence is kept privately for offline ad removal. No microphone, camera or location access is needed for graphing. File import/export uses the Android document picker. Opening screen-mirroring settings is optional; screen transmission, if enabled by the user, is managed by Android and the selected receiver.
